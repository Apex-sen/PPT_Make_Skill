# 使用指南

1. 提供论文 PDF 和实际使用的 PPTX 模板，说明汇报时长、语言和受众。
2. 先精读论文，形成术语表、证据表和逐页大纲，并标注章节/页码/公式/Figure/Table 依据。
3. 用户确认大纲后再制作。方法部分要解释输入输出、设计动机、参数更新/冻结和训练/推理差别。
4. 结果页优先使用原论文完整 Figure/Table，每页可见实验目的、关键观察和解释边界。
5. 复用模板真实页面，而不是只模仿主题色。
6. 导出 PDF/PNG 并逐页检查，问题页返工后再交付。

辅助脚本仅提供常见文件操作，不代替论文精读和人工视觉验收。PPTX 渲染需要 LibreOffice；PDF 裁切需要 PyMuPDF；PPTX 编辑需要 python-pptx。
