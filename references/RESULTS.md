# 结果页与原论文Figure完整性：强制规范（V3.2）

## 0. 一张Figure是一个完整的证据单元（最高优先级）

- 原论文中编号为 **Fig. 3** 的多子图组合，无论是2联、4联或6联图，**默认完整展示为一张图**。不得为了好看自行将上下排拆成两个互不连贯的Figure，尤其是共享图例、坐标轴、统计标注的原图。
- 结果图的统一图例、全部轴标题/刻度/单位、面板标签(A/B/C)、图内文字、重要脚注/图题都是原图不可缺少的组成部分。
- 若整张图放入左侧后仍看不清，**先扩大图像区域、缩短右侧分析、增加页面，不直接拆图**。仍有困难时允许下一页放辅助局部放大，但前一页必须有整图及完整图例，局部放大清楚标注“Fig.X 的局部放大”，并能追溯原图区域。
- 如用户明确要求拆图，可分别截取子图，但每一页必须显示对应原图图例、坐标单位、来源，并由人工审查；不能把剪出来的图伪称为原来的完整Figure。

## 1. 截图前先找外边界；裁切后核对四周

1. 先从论文PDF导出整页预览，确认Figure的位置、图题、边缘坐标轴、图例的位置以及整个组合的范围。
2. 选择**包含完整图表的最外侧边界**（不是仅选坐标网格内部），左右留给纵轴标题和刻度，上下留给图标题、横轴刻度、图例、单位和脚注。
3. 使用 `extract_pdf_region.py` 的 **--padding-pt 默认12pt外扩**，另外生成 `--preview` 叠框预览。原图渲染推荐300–450 DPI。
4. 截取图外四边不得有文字笔画贴边；程序给出边缘像素预警，但**自动预警不能代替人工检查**。若原图横向图例处于页面最右侧，尤其要人工查看。
5. 将**完整截图与原PDF同一页面**并排看：检查全部子图、x/y轴标签、图例、实验条件、统计符号、标题和页内脚注。
6. PPT生成后导出PDF或逐页PNG，再检查一次。不允许以“Python成功保存图片”代替完整性验收。

## 2. 每个结果页必须有三块显式分析，不能只有图片

推荐（如用户模板允许）：**左侧或中央：原论文整张Figure（60–75%宽）；右侧：有实质内容的三块分析（25–40%宽）**：

- **实验目的**：说明作者要检验的假设、比较方法和场景（通常1–2句）。
- **关键观察**：明确说出图中哪个组/哪条曲线/哪项指标与什么对照发生什么变化；不能空写“效果很好”。
- **结果解释**：该图允许得出什么结论、与科学问题的关系及证据边界（通常1–2句）。

可在底部增加 `来源：作者（年份），Fig. N，论文PDF第X页`。右侧必须是**PPT上可见的文字**，不是仅放在备注中。

构建脚本的 `kind: "result"` 页面要求元素角色：`paper_figure`、`result_purpose`、`result_observation`、`result_interpretation`，并且主图 `figure_scope: "full"`。默认检查“主图在左、分析在右”；例外需要在计划中记录解释。

## 3. 实验结论与原图对齐

- 展示论文原始 Figure / Table，未经明确允许不重新提取数据画新柱状图、折线图。
- 不更换方法颜色、不修改坐标范围、不遗漏反例或重要对照、不凭准确率宣称隐私已得到攻击实证验证。
- 在分析前读懂原图的子图结构：上/下排的含义、图例共享范围、各场景、评价指标与样本量。
- 当标题说“优于”时明确优于何种具体比较方法、何种指标与实验条件，不能将局部表现泛化成全场景。

## 4. 出图验收：一票否决

出现任意情况必须返工，不得交付：

- 任何轴标题/标签/刻度/单位、共享图例、面板、图题或重要注释被裁掉；
- 用户未授权却把同一整图拆成不连贯的多图；
- 原始图像被拉伸变形，或原图字号投影时不可辨认；
- 研究结果页仅有图无分析，或分析空泛不指向实际观察；
- 声称原图，实际是未经说明重绘的图表。

## 5. 推荐命令

```bash
python skills/ppt-make-skill/scripts/extract_pdf_region.py \
  --pdf input/paper.pdf --page 8 --rect 110 90 510 360 \
  --padding-pt 14 --dpi 400 --figure-id Fig3 \
  --output outputs/Fig3_full.png --preview outputs/Fig3_crop_check.png \
  --metadata outputs/Fig3_source.json
```
