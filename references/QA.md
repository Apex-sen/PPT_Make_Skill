# 制作验收与质量清单

## 内容与科学性
- [ ] 研究问题、方法、实验和局限可追溯至论文。
- [ ] 原文事实、作者结论、汇报者分析、未验证假设已区分。
- [ ] 术语已核对，缩写未靠猜测展开。
- [ ] 方法输入/输出、参数更新/冻结、训练/推理路径已解释。
- [ ] 结果标题没有超出证据范围；必要的负面结果和边界未隐藏。

## 模板与布局
- [ ] 封面、结束页、校徽、主题色、字体层级、页码等模板元素保留。
- [ ] 无文字溢出、元素遮挡、页边界外对象。
- [ ] 正文、图例、表格和公式在投影尺寸下可读。
- [ ] 没有为了填满页面而添加无依据内容。

## 图表与公式
- [ ] Figure 的完整边界、轴、单位、面板标签、共享图例和脚注完整。
- [ ] 原图未拉伸、擅自重绘或改变颜色/坐标范围。
- [ ] 每张结果页可见实验目的、关键观察和结果解释。
- [ ] 图表来源含 Figure/Table 编号及论文页码。
- [ ] 关键公式与原文逐项核对，并在导出 PDF/PNG 中检查。

## 交付
- [ ] PPTX 可打开、可编辑。
- [ ] 已导出 PDF/PNG 并逐页检查。
- [ ] 公式图片、原始论文图等非可编辑对象已说明。
- [ ] 文件路径真实有效，未提供猜测的下载链接。

## 一票否决
完整 Figure 被误裁、结果页没有可见分析、关键公式乱码、严重重叠/溢出、模板被整体替换或结论无原文依据，任一项出现都必须返工。
