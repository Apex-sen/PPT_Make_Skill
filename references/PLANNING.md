# 科研汇报结构与逐页规划

## 汇报逻辑
默认按「研究背景 → 核心科学问题 → 相关研究与现存问题 → 整体框架 → 核心方法 → 实验验证 → 创新与局限 → 未来研究 → 总结」展开。根据论文实际内容调整，不机械照搬章节目录，也不为了结构完整虚构学术争议。

## 逐页计划字段
制作前为每页记录：页码、标题、唯一核心论点、页面内容、原文出处（章节/页码/公式/Figure/Table）、所需视觉材料、结果分析、讲稿备注、复用的模板页。无法追溯来源的事实须进一步核查、删除或明确标注为汇报者分析。

## 方法规划
先解释完整框架，再拆解模块。逐页说明输入、输出、计算步骤、参数更新/冻结、训练与推理区别、模块间数据流、设计动机、代价与局限。复杂方法允许增加工作示例，不得为了页数牺牲正确性。

## 结果规划
每个实验页需注明验证目的、对比对象、实验条件、关键观察和结论边界。优先整张原始 Figure/Table；不未经许可二次抽数重绘。

## 时间与页数
15–20分钟可先规划约18–28页，再根据方法复杂度与图表可读性调整。图表不可读时应加页或缩短文字，而不是持续缩小图表。
