# 公式排版与乱码验收

## 来源核对
每条关键公式记录原文编号、页码/章节。逐项核对上下标、希腊字母、集合符号、转置、范数、求和范围、分母、括号、归一化常数和编号。区分原文公式与汇报者辅助推导。

## 排版优先级
优先使用经目标 Office/WPS 版本验证的原生公式对象；其次使用论文 PDF 高清完整公式；必要时用数学排版引擎生成透明公式图，并同时提供 .tex 源码。公式图片不是可编辑公式对象，需说明限制。

## 一致性与验收
统一数学字体、字号、颜色和编号样式；同一符号含义不得改变；公式说明不能重叠；不把未经渲染的 LaTeX 或 PDF 乱码直接放进普通文本框。最终导出 PDF/PNG 后逐条检查上下标、缺字、根号、分式、求和范围、编号和边界。关键公式未通过不得交付。
